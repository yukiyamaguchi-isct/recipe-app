## このフェーズの分け方

**下から積む**（Phase 4 と同じ）。保存の経路（検証 → Repository → API）を先に固め、画面はその上に乗せる。**S-04 側の導線（`編集` / 「編集する」）は最後に開ける。** 先に開けると、保存できない編集画面へ入れる期間ができる。

| 層                      | 段階   | 何ができるようになるか                                      |
| ----------------------- | ------ | ----------------------------------------------------------- |
| 部品（整形・検証）      | 2      | 下書きを保存形に整え、空行・未入力を判定できる              |
| 保存（Repository・API） | 3〜4   | 材料と手順を所有者のレシピにだけ、まとめて書き込める        |
| 画面の骨格              | 5      | `/recipes/<id>/edit` が開く（認可・見つからない場合を含む） |
| 共有部品の切り出し      | 6〜7   | 確認ダイアログとカテゴリのラベルを S-04 / S-02 と共有できる |
| 入力                    | 8〜9   | 材料の行と手順を直せる・足せる・消せる                      |
| 保存と離脱              | 10〜11 | 保存して S-04 に戻れる。未保存の変更を失わせない            |
| 導線                    | 12〜13 | S-04 と確認画面から編集画面へ入れる                         |
| 実測                    | 14     | 実機と本番で通しで確認できている                            |

**視覚仕様は各段階で当てる**（design.md 6.1 が確定値の対応表）。
